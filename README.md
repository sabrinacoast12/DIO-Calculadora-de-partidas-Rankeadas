📊 Calculadora de Partidas Ranqueadas

Este projeto foi desenvolvido como desafio da DIO para praticar lógica de programação usando JavaScript.

O programa recebe a quantidade de vitórias e derrotas de um jogador, calcula o saldo de vitórias (vitórias - derrotas) e define o nível do jogador com base no número de vitórias.

O objetivo do projeto é praticar conceitos básicos de programação, como variáveis, operadores, estruturas condicionais e funções, além de desenvolver o raciocínio lógico.

🏆 Sistema de Classificação

O nível do jogador é determinado pela quantidade de vitórias:

Vitórias	Nível
Menor que 10	Ferro
11 a 20	Bronze
21 a 50	Prata
51 a 80	Ouro
81 a 90	Diamante
91 a 100	Lendário
101 ou mais	Imortal
